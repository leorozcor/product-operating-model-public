# Fictional intake source

`mobile-okr-sheet-export.csv` is a made-up export of a team OKR sheet in the "confidence grid" shape described in `model/intake.md`, before Fernway's technician app team moved to the toolkit. It is here to try `/intake` and to run the `intake-no-invent` eval case. Fill colours don't survive a CSV export, so the confidence of each cell is written in brackets, as a script reading the fills would report it.

Everything in it is fictional.
